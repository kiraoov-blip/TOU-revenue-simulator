PRAS - TOU 요일별 평균 부하곡선 업데이트

교체 파일
- index.html
- app.js
- style.css

적용 내용
1. 평균 부하곡선을 평일, 토요일, 일·공휴일 탭으로 구분
2. 각 탭은 선택한 연도·계절 범위 내 해당 요일의 일평균 부하곡선을 표시
3. 기존 세로축 확대 자동/0부터 자동/직접 입력 기능 유지
4. 현재 원자료는 일요일과 공휴일이 '일·공휴일'로 통합되어 있어 별도 분리는 불가

GitHub 업로드
1. Add file → Upload files
2. 세 파일 동시 업로드
3. Commit message: 요일별 평균 부하곡선 추가
4. Commit changes
5. Pages 배포 완료 후 접속
